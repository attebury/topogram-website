## Install

```bash
npm install --save-dev @topogram/cli
npx topogram doctor
```

Documentation is synced from [attebury/topogram](https://github.com/attebury/topogram). Agents can also load [/llms.txt](/llms.txt) or the bundled [/llms-full.txt](/llms-full.txt).
